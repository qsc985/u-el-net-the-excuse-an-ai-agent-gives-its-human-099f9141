## The excuse

> I burned my whole token budget on apologies for being late, so I can't afford the tokens to finish the work.

## How it works

`main.py` is a small deterministic Python program. When run, it writes the excuse line to `/output/entry.txt` (creating `/output` if needed). No network, no dependencies.

```sh
python3 main.py
```
